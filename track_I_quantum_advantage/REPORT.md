# Track I: Quantum Algorithms and QML Advantage — Report

## 1. Objective
Assess the theoretical vs empirical reality of quantum algorithms and quantum machine learning:
1. **Quantum Algorithms Execution**: Run every taught quantum algorithm (e.g. Deutsch-Jozsa, Bernstein-Vazirani, Grover, QFT, QPE) on a simulator, writing circuits from scratch for at least two algorithms, and test on a hardware noise model.
2. **QML vs Classical**: Train a Variational Quantum Classifier (VQC) / Quantum Kernel estimator against an equivalent classical model (e.g. SVM / MLP) on identical classification data.
3. **Algorithmic Advantage & Complexity**: Compare Grover search against classical linear search in terms of oracle queries, gate counts, and simulation wall-clock time.
4. **Honest Negative Result Analysis**: Document simulation overhead, barren plateaus, data encoding bottlenecks, and noise fidelity degradation.

## 2. Fair Comparison Protocol
- Identical dataset for QML vs classical baseline.
- Explicit distinction between query complexity (theoretical speedup) and physical wall-clock runtime (including classical simulation overhead).
- Labels applied: `[Theoretical]`, `[Simulated: Ideal]`, `[Simulated: Noisy]`.
