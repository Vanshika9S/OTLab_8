# Technical Report Index & Structure

This folder contains the consolidated technical report for **Assignment 8: Optimize Anything**.

1. **Executive Summary**: Overview of problem domain, vibe-coding methodology, and aggregate performance improvements.
2. **Main Case Study (Track E)**: University Exam Timetabling problem statement, mathematical formulation, evidence of inefficiency, baseline vs optimized comparison, and trade-off analysis.
3. **Curriculum Track Reports (Tracks A to J)**:
   - Track A: Continuous Optimization (1st/2nd order, backprop, landscapes)
   - Track B: Discrete Optimization (Greedy, ILP, Branch-and-Bound, DP, QUBO)
   - Track C: Quantum Optimization (QAOA on QUBO, VQE, noise & shot analysis)
   - Track D: Submodular, Parallel & Distributed Optimization (Amdahl/Gustafson, FedAvg, MGDA/GradNorm)
   - Track E: University Exam Timetabling
   - Track F: Compiler Optimization Passes & Graph Coloring Register Allocation
   - Track G: xv6 OS Optimization (Scheduler / Memory / Buffer Cache)
   - Track H: DBMS Workload Optimization & Index Selection
   - Track I: Quantum Algorithms & QML Advantage (Classical vs Quantum, Grover, Kernels)
   - Track J: Software-Engineering Bottleneck Optimization in Real Codebase
4. **Vibe Coding, AI Register & Tool Comparison**:
   - Comprehensive AI tool register
   - Head-to-head AI tool comparison
   - Documented AI failures and lessons learned
5. **Answers to the 10 Mandatory Questions** (Section 11).
